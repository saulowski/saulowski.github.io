# Toyshop Flights Spotting Game: Privacy Policy

Last updated: November 2026

Toyshop Flights Spotting Game is a personal tool for the [Toyshop Flights](https://www.youtube.com/@ToyshopFlights) YouTube channel. During live streams, viewers guess in the chat where a landing aircraft has come from, and the first correct guess scores points. It uses YouTube API Services to do this.

## What the game reads

While a round is open, the game reads the stream's live chat, including each comment's text, time, author name and YouTube channel ID. Comments that don't win a round are not saved. They are only held in memory while the game is running.

## What the game saves

- **Winning guesses:** the viewer's YouTube name and channel ID, the points earned, the guess text, and the comment's ID and time.
- **Blocked viewers:** the name or channel ID of any viewer blocked from the game.

## What the game shows and posts

Winners' YouTube names and scores appear on the stream's scoreboard. The game also posts a message in the live chat announcing each winner.

## Where the data is kept

The data is stored on the channel owner's computer, with a backup in a private GitHub repository. The sign-in used to access YouTube stays on that computer.

## Sharing

The data is not sold, and it is not shared with anyone, apart from being shown on stream as described above and stored with the services named on this page.

## Google and YouTube

By taking part in the live chat, you are also subject to the [YouTube Terms of Service](https://www.youtube.com/t/terms). Google's handling of data is described in the [Google Privacy Policy](https://policies.google.com/privacy). The channel owner can remove this tool's access at any time from [Google's security settings](https://myaccount.google.com/permissions).

## Your choices

To ask for your data to be removed from the game, or with any question about this policy, email [saulojoonior@gmail.com](mailto:saulojoonior@gmail.com). If you don't want to take part, just don't post guesses in the chat.
